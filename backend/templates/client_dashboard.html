ركّب البوت على موقعك

انسخ الكود ده وحطه في موقعك قبل </body> — هيظهر زرار «كلّمنا» في ركن الصفحة، يفتح البوت بتاعك بالمنيو وروابط الدفع. شغال مع WordPress وShopify وWix وأي موقع.
فين أحط الكود؟ WordPress: إضافة «WPCode» ← Add Snippet ← Footer ← الصق الكود.
Shopify: Online Store ← Themes ← Edit code ← theme.liquid ← الصقه قبل </body>.
Wix: Settings ← Custom Code ← Add Code ← Body - end.
موقع عادي: الصقه قبل </body> في كل صفحة.
تقدر تغيّر data-label لكلام الزرار، و data-position="left" عشان يبقى على الشمال.
